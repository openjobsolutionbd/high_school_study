# নতুন সাবজেক্ট/ক্লাসে এই আর্কাইভ-টুল যোগ করার নিয়ম

`book_tools.py` স্ক্রিপ্টটা সম্পূর্ণ জেনেরিক — কোনো সাবজেক্টের নাম, চ্যাপ্টার সংখ্যা বা
ফাইলনেম প্যাটার্ন এখানে হার্ডকোড করা নেই। নতুন যেকোনো সাবজেক্টে ব্যবহার করতে নিচের
৪টা ধাপ অনুসরণ করুন।

## ধাপ ১ — ফোল্ডার স্ট্রাকচার বানান

```
<subject>/
├── html/
├── markdown/
│   ├── chapter-01-....md
│   ├── chapter-02-....md
│   └── ...
└── images/
    ├── original-book-pages.zip   ← মূল স্ক্যান করা বইয়ের সব পাতা
    ├── book-config.json          ← নতুন করে বানাতে হবে (নিচে দেখুন)
    └── book_tools.py             ← এই ফাইলটা কপি করুন, অপরিবর্তিত রাখুন
```

## ধাপ ২ — সূচিপত্র থেকে চ্যাপ্টার রেঞ্জ বের করুন

বইয়ের প্রথম কয়েক পাতার মধ্যে সূচিপত্র (সূচি) খুঁজে বের করে প্রতিটা অধ্যায়ের বই-পৃষ্ঠা
রেঞ্জ নোট করুন (যেমন: অধ্যায় ১ → পৃ. ১–১৬)।

## ধাপ ৩ — অফসেট বের করুন

অধ্যায় ১-এর প্রথম পাতাটা (বই পৃ. ১) ইমেজ জিপের কোন নম্বরে আছে সেটা চোখে দেখে যাচাই
করুন। অফসেট = ইমেজ নম্বর − বই পৃষ্ঠা নম্বর। এই একই অফসেট পুরো বইয়ে স্থির থাকে
(সাধারণত কভার+প্রিলিমিনারি পাতার সংখ্যার সমান)। কমপক্ষে ২-৩টা অধ্যায়ের শুরুর পাতা
মিলিয়ে অফসেটটা নিশ্চিত করে নিন।

## ধাপ ৪ — `book-config.json` বানান

এই ফরম্যাট অনুসরণ করুন:

```json
{
  "subject_name": "সাবজেক্টের পূর্ণ নাম — ক্লাস",
  "zip_file": "original-book-pages.zip",
  "image_prefix": "ইমেজ ফাইলের নাম যেভাবে নম্বরের আগ পর্যন্ত থাকে",
  "image_offset": 5,
  "markdown_dir": "../markdown",
  "chapter_file_pattern": "chapter-{:02d}-*.md",
  "chapters": [
    { "num": 1, "title": "অধ্যায়ের নাম", "start": 1, "end": 16 },
    { "num": 2, "title": "...", "start": 17, "end": 36 }
  ]
}
```

**ফিল্ড ব্যাখ্যা:**

| ফিল্ড | মানে |
|---|---|
| `zip_file` | ইমেজ জিপের ফাইলনেম (images/ ফোল্ডারের ভেতরে) |
| `image_prefix` | ছবির ফাইলনেমের সংখ্যার আগের অংশ (যেমন `IMG_page-` হলে `IMG_page-0006.jpg`-এর prefix `IMG_page-`) |
| `image_offset` | ধাপ ৩-এ বের করা অফসেট |
| `markdown_dir` | images/ থেকে markdown/ ফোল্ডারের আপেক্ষিক পাথ |
| `chapter_file_pattern` | মার্কডাউন ফাইলনেমের প্যাটার্ন, `{:02d}` জায়গায় চ্যাপ্টার নম্বর বসবে |
| `chapters` | প্রতিটা অধ্যায়ের নম্বর, শিরোনাম ও বই-পৃষ্ঠা রেঞ্জ |

## ব্যবহার (সব সাবজেক্টে একই কমান্ড)

```bash
cd <subject>/images/
python3 book_tools.py list
python3 book_tools.py page 25
python3 book_tools.py page 37 52
python3 book_tools.py chapter 3
python3 book_tools.py search "শব্দ/বাক্যাংশ"
python3 book_tools.py search "শব্দ" --fuzzy     # বানান/OCR ভুল সহনশীল
```

`book_tools.py` স্ক্রিপ্টটা কখনো এডিট করার দরকার নেই — শুধু `book-config.json`
বদলেই নতুন সাবজেক্ট চালু করা যায়।
